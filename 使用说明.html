01从哪里开始

直接玩游戏 →打开 index.html，点击“开始夜巡”。无需安装开发工具。看设计和素材 →浏览立绘、动画、场景、界面与音乐，再按目录查看原文件。修改或复用 →先读源码构建方法；需要生成新动作时，再看 H3 工作流。

文件夹根目录的 index.html 是游戏入口，使用说明.html 是本页，素材总览.html 是素材浏览页。三个文件各自承担一个用途。

02离线试玩

  1. 在文件夹中双击 index.html，用 Edge、Chrome 等支持 Canvas/WebAudio 的浏览器打开。
  2. 点击“开始夜巡”。背景音乐需要首次点击或按键后才能启动；暂停菜单中可开关声音。
  3. 移动换线、持续射击，收集微光成长；使用炉火和绽放处理危险，完成夜巡。

游戏代码、图片、动画和音乐都已内嵌到 index.html，离线试玩不需要 Python、Node.js、ComfyUI 或模型文件。平台在线排行榜等联网能力不属于离线试玩保证。

动画图集怎么读

透明 PNG 是游戏实际使用的帧图集，GIF 是便于观看的预览。不要把整张 PNG 当成单帧显示；按对应 manifest 中的帧矩形裁切。

  • 主角动画参数：w/h 为每帧尺寸，n 为帧数，rects 为帧左上角位置，ax/ay 为局部锚点，clips 描述播放区间。
  • 怪物动画参数：fw/fh 为帧尺寸，fps 为播放速度，eq 为工程绘制比例补偿。GIF 的完整演示用时可能与游戏攻击状态用时不同。

相同素材在分类目录和 src 下可能各有一份：分类目录用于浏览，src 中的副本供原构建脚本使用。修改游戏素材时，要修改构建实际引用的那一份。

04修改源码与重新构建

src/shell.html＋src/game.src.js＋src/assets.json / art / audio→tools/build.py→index.html
文件修改范围
src/game.src.js游戏规则、状态、输入、绘制和程序音效。
src/shell.html页面结构、界面样式和按钮布局。这是模板，直接双击不能作为完整游戏试玩。
src/assets.json内嵌角色/怪物图集及静态资源行，对应源码中的 ASSET 占位符。
src/art / src/audio构建引用的图片和 4 首音乐。保留文件名可以直接重新构建；新增素材需要同步代码引用。
  1. 准备 Python 3。构建仅使用标准库，无需安装 pip 或 npm 依赖。可选语法检查另需 Node.js，并且终端能找到 python。
  2. 在 public-share 根目录打开终端，修改对应文件后先运行检查。
  3. 运行构建生成新的 index.html，重新打开或刷新游戏，检查实际效果。
# 查看源码构建结果与当前 index.html 是否一致
python tools/build.py --check

# 可选：用 Node.js 检查游戏脚本语法
node tools/syntax.js

# 重新生成根目录 index.html
python tools/build.py

--check 会打印“一致”或“不同”。修改源码后看到“不同”是正常的，运行最后一条命令会更新游戏入口。不要只编辑 index.html 后又重建，否则手工改动会被源码覆盖。

替换已有角色/怪物图集时，需要同步实际图集数据、帧尺寸、帧数与锚点。分类目录中的 manifest 是复用参考；仅修改它不会自动注入 src/assets.json。本包未提供从新视频到游戏资源的一键接入工具。

完整环境记录见 DEPENDENCIES.md。当前源码已经核对，可构建出整理时的离线入口；这不等于每一次后续修改都已通过游戏验收。

05复用 MiniMax H3 视频工作流

这批素材采用本地 ComfyUI H3流程。只有需要重新生成动作视频时才配置这部分；查看素材和运行游戏不需要它。

先准备环境与参考图

  1. 准备能加载这些 H3 模型与节点的 ComfyUI 环境。原项目记录是 ComfyUI 0.38.0、Turbo 节点 1.2.3、6 步 simple、SigmaShift 12/3、Kitchen 注意力。具体提交号及完整节点清单见 dependencies.json。
  2. 将 08-video-workflows/inputs 中的 8 张 PNG按原文件名复制到自己配置的 ComfyUI 输入目录。文件名需要和 LoadImage 节点一致；节点缺图时重新选择相应文件。
  3. 按下表准备模型，确认加载器下拉列表能识别；Turbo 插件安装时保留其自带辅助文件。
  4. 在本地文件夹找到所需的中文长文件名 JSON，拖进 ComfyUI 画布。先检查模型、参考图和保存前缀，再手动运行一条。

模型权重、ComfyUI 本体、Turbo 插件和 Python/CUDA 运行时没有打进本资料包。版本表记录原工程使用配置；它不是完整环境锁文件，其他机器的显卡与量化支持需要另行配置。

06可选：绿幕视频清理

clean_green_video.py 用于把绿背景归一化并移除孤立小碎点。它输出仍带绿底的 MP4，不输出透明 PNG。仅在确实需要该处理时安装对应依赖。

# 在 public-share 根目录运行
python -m pip install -r requirements-assets.txt
python tools/clean_green_video.py input.mp4 output.mp4

输入和输出使用不同文件名。输出旁还会写出 output.cleanup.json，记录处理帧数和参数。

可选参数用途
--key-warm-effects额外剔除生成出的暖色效果；可能影响角色原有暖色，只在对应素材上使用。
--retain-body-and-right-puffs保留本体与右侧雾团，面向本项目大夜怪相关素材。

依赖版本见 requirements-assets.txt。该依赖文件只用于可选清理工具，不用于安装 ComfyUI/H3 环境。此次整理没有重跑完整视频清理。

07常见问题

打开后只有界面，游戏没有运行

确认打开的是根目录 index.html。src/shell.html 是等待构建的模板；素材总览.html 和使用说明.html 也不是游戏入口。

没有声音

先点击“开始夜巡”或进行一次按键交互，再检查游戏内声音开关、浏览器标签页静音和系统音量。浏览器通常需要用户交互后才能启动音频。

修改了素材总览中的图片，游戏里没有变化

游戏读取内嵌数据与 src 下的构建资源。修改分类目录仅影响浏览展示；按源码章节修改构建输入，再重新运行 tools/build.py。

命令提示找不到 python 或 node

检查对应工具是否安装并能从终端调用；重新打开终端后再试。构建只需 Python，Node 仅供可选语法检查。普通离线试玩不需要二者。

H3 工作流提示缺少节点、模型或图片

对照依赖清单检查 ComfyUI/Turbo 节点与五个模型。8 张输入参考图需要保留原名并放入 ComfyUI 实际输入目录；必要时在 LoadImage 节点重新选择。更换模型或量化方案可能改变效果和显存需求。

能否保证在另一台机器复现相同视频

本包保留种子、提示词、参数和参考图，但原环境记录不覆盖每项运行时依赖。不同软件、驱动、显卡与注意力实现可能影响输出；请先运行一条检查。

排行榜能否断网使用

离线试玩检查覆盖开局加载、战斗输入和暂停。平台在线排行榜等联网能力需要相应平台环境，不作为独立离线文件的保证。
