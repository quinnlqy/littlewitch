# 制作过程网页与演示资料

这里集中收录视频制作过程中整理的五个网页。下载仓库后，打开 [制作过程总入口](index.html)，或直接打开以下 HTML。GitHub 文件页默认显示 HTML 源码；下载后用浏览器打开即可正常浏览和试听，无需启动服务。

| 网页 | 内容 |
| --- | --- |
| [小魔女形象演变](character-evolution/小魔女形象演变.html) | 从早期立绘到当前角色；保留备选方案、曾采用的栗红发版本与完整原图。 |
| [小魔女动作状态图](action-map/小魔女动作状态图.html) | 16∶9 动作图：idle、移动、加速、射击、施法与绽放，附 GIF。 |
| [UI 变化路径](ui-evolution/小魔女UI变化路径.html) | 从程序界面、月光悬浮与童话徽章方案，到选定方案后的实际界面。 |
| [电脑与手机 UI 对照](ui-evolution/电脑与手机UI对照.html) | 视觉方案、当前战斗、暂停方案、暂停实装，四组双端对比。 |
| [程序音效与 MiniMax 配乐](audio/小魔女音效与配乐.html) | 41 项程序音效、3 段程序旋律及 4 首 MiniMax 配乐，可直接试听。 |

除形象演变的长页外，动作图、UI 路径、双端对照和声音试听均按 16∶9 一屏展示。素材、GIF、音频、原图及必要说明随网页保留；本机核对记录、会话记忆、测试日志和临时文件不在公开包中。

这些资料基于 2026-10-29 的项目文件整理，本次于 2026-10-30 纳入公开仓库。根目录游戏仍沿用既有公开版本；教程里的后续截图、音量参数或界面细节可能与该游戏快照有差异。各页保留概念 / 实装、历史 / 当前、旧版兼容 / 回退等标注。

原始 MiniMax 配乐与素材来源状态沿用 [仓库来源说明](../素材来源与使用说明.md)。各目录有独立 README 和来源清单，仓库根目录 `manifest.json` 记录此次公开文件的大小与 SHA-256。
