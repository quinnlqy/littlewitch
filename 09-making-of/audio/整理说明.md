# 小魔女：程序音效与 MiniMax 配乐

直接打开 `小魔女音效与配乐.html`，16∶9 一屏试听。音频均内嵌于 HTML，单独复制 HTML 也能离线听。页面左侧为程序合成声音，右侧为 MiniMax 生成音乐；支持完整列表、提示词查看、总音量和停止播放。

## 01 程序生成

DeepSeek 编写音效代码，运行时由 Web Audio 的振荡器、噪声、滤波和包络合成。

- `音效试听WAV`：当前代码的 41 项音效，包含射击、受伤、拾取、怪物、首领、阶段提示，也保留旧版兼容与回退项。WAV 是本轮从代码离线渲染的试听导出，游戏本身原先没有这批独立音效文件。
- `程序旋律试听`：星光绽放短旋律，以及普通 / 首领战背景 MP3 不可播放时的备用程序旋律片段。
- `代码/程序音频合成.js`：从当前游戏提取的 Audio7、SFX、SFX_TRIM、StarLoop 和备用旋律。独立试听取消了游戏 BGM 联动；音色与音量参数保留原逻辑。

旧版雷光、爆裂、落星与魔法爆发在完整列表单独标记。当前第一关只开放炉火。程序合成的 win / lose 是结算音乐不可用时的回退，与 MiniMax MP3 分开。

## 02 MiniMax 生成

生成记录位于原项目 `tools/gen_music.py` 和 2026-10-23 工作记录：经 TokenHub 调用，模型名 minimax-music-v3.0。

| 文件 | 用途 | 当前时长 |
|---|---|---|
| bgm_normal.mp3 | 普通战斗 / 巡夜 | 73.41 秒 |
| bgm_boss.mp3 | 首领战 | 100 秒 |
| bgm_win.mp3 | 通关结算 | 9 秒 |
| bgm_lose.mp3 | 失败结算 | 7 秒 |

- `原始MP3`：逐字节复制当前 src/audio 文件，以 SHA-256 核对。
- `试听MP3`：只校准峰值并重编码，便于单独试听；并非重新生成的音乐。
- `生成提示词.json`：从生成脚本中仅提取模型与四首提示词，没有执行生成，也没有复制账户配置。
- `原项目来源说明.md`：保留公开资料中已有的来源及使用说明，不额外指定新许可。

历史记录说明，通关与失败音乐由模型生成的长曲裁剪并淡出；普通战斗与首领战也经过时长 / 首尾处理。最终文件时长与提示词里的目标时长不同。

## 可用于视频的归类

程序音效：普通射击、强化射击、小魔女受伤、微光 / 星辉 / 茶杯拾取、射击升级、炉火、怪物及首领反馈。

MiniMax 配乐：普通战斗、首领战、通关与失败四首。

另外：星光绽放期间的短旋律也由程序合成，单独列在程序生成组，不混入 MiniMax 四首音乐。

源项目：原工程/src/game.src.js 与 src/audio。详细来源、导出参数、随机种子和音频校验值见 `声音来源与导出清单.json`。本目录为公开制作过程资料中的声音分类与试听包。
