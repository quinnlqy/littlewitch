# 程序音效与 MiniMax 配乐

[打开离线试听网页](小魔女音效与配乐.html) · [完整整理说明](整理说明.md)

左侧是程序合成音效，右侧是 MiniMax 配乐。支持音量、停止播放、完整列表、生成提示词与全屏；音频已内嵌 HTML。

- `01-程序生成`：41 项音效的试听 WAV、星光绽放短旋律、普通 / 首领战备用程序旋律，以及提取的合成代码。旧版兼容、通关 / 失败合成回退单独标注。
- `02-MiniMax配乐`：普通战斗 73.41 秒、首领战 100 秒、通关 9 秒、失败 7 秒。四首原始 MP3、峰值校准试听副本、四首生成提示词与原项目来源说明分别保留。

WAV 为从代码离线渲染的试听导出，游戏原本实时合成，不读取这批 WAV。生成记录为 TokenHub / minimax-music-v3.0；结算音乐经过长曲裁剪与淡出。`声音来源与导出清单.json` 记录源快照校验值、音频校验值与导出处理。

素材使用范围沿用仓库的 [来源说明](../../素材来源与使用说明.md)，本次未额外指定许可证。
