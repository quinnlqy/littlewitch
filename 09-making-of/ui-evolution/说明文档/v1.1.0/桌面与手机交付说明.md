# A 月光悬浮 · 桌面与手机 UI 视觉参考 v1.1.0

日期：2026-10-23。已选视觉方向：A「月光悬浮」。本版新增桌面 16:9 效果图，并收录同风格手机效果图，供界面实现时对照。两张图片均为 imagegen 生成式概念稿；游戏界面尚未据此实现。

## 桌面版

![桌面版](A月光悬浮-桌面版.png)

背景：连续铺满游戏容器，保持深紫夜色、柔和月光、村庄与湖面。UI 使用透明深紫底、奶油白细线和少量光晕。

| 位置 | 显示内容 | 设计目的 |
| --- | --- | --- |
| 左上 | 生命、射击等级、成长进度 | 让角色状态固定在同一区域 |
| 顶部中央 | 阶段与已用时间；Boss 名称、单根血条、两道阶段刻度与当前阶段短名 | 统一关卡与 Boss 信息 |
| 右上 | 分数、暂停按钮 | 使用桌面宽度展示分数，暂停便于定位 |
| 左下 | 炉火、绽放两枚圆形按钮，水平同组 | 统一两个技能的操作与资源反馈 |
| 炉火按钮内 | 火焰图标、名称、0/3～3/3；附 Z 键提示 | 库存与释放入口在一起 |
| 绽放按钮内 | 星花图标、名称、能量/就绪/持续倒计时；附 E 键提示 | 状态直接表现在技能自身 |
| 右下 | WASD 移动、空格射击、P 暂停的简短提示 | 以低优先级帮助玩家了解操作 |

桌面两枚技能按钮以 64×64 CSS 像素、间隔 16 为实现基准，随可用空间采用规范中约定的紧凑布局。生成图中的圆环、字号和键帽是视觉参考，最终按真实窗口尺寸校准。快捷键标记是按钮上的提示，鼠标点击对应技能也直接生效。

## 手机版

![手机版](A月光悬浮-手机版.png)

左侧摇杆，右侧炉火与绽放上下成组。生命和射击成长位于左上，阶段/Boss 居中，暂停位于右上。按钮内显示资源，触屏自动射击。手机延续桌面的透明材质、暖橙火焰与蓝紫星花，按触摸空间重新排布。

手机两主键以 56×56 CSS 像素、竖向间隔 12 为基准，平板采用 72×72、水平间隔 16。具体核心尺寸、预留空间和安全区域按 v1.9.0 修改说明与完整适配要求落实。

## 给 DeepSeek 的补充要求

界面视觉方向已经确定使用 A「月光悬浮」。请同时参照本目录的桌面版与手机版效果图实现，保持两端材质、颜色、图标语义一致，按各自布局安排控件。

电脑界面：左上生命与射击成长，顶部中央阶段/时间与 Boss 信息，右上分数/暂停，左下炉火 Z 与绽放 E 水平同组，右下简短键盘提示。手机界面：左侧摇杆、右侧两技能竖排，触屏自动射击，战斗时收起实时分数与秒数。平板左下摇杆、右下两技能横排。

技能只有炉火和绽放。炉火次数始终在炉火按钮内，奖励火种飞入其实际屏幕位置；绽放能量/状态始终在绽放按钮内。按钮保持实时可点、可禁用和状态反馈，库存与能量依据真实玩法状态更新。

背景覆盖容器，480×270 战斗核心等比完整显示，UI 独立适配。主要交战区域清楚可见，控件、按键提示和装饰光晕避开角色、敌弹与 Boss 预警。数值和文字由实际 UI 绘制，继续使用现有场景与角色资产。参考图中敌弹与背景细节用于衬托界面，玩法、敌人技能与关卡编排以项目规则为准。
