# A 月光悬浮 · 桌面与手机 UI 视觉参考 v1.2.0

日期：2026-10-23。视觉方向：A「月光悬浮」。本版明确灯怪火种飞入炉火标识的反馈，以及绽放累计进度条与完整状态。v1.0.0、v1.1.0 保留。

## 1 桌面与手机布局

桌面：左上生命、射击等级与成长进度；顶部中央阶段、已用时间及 Boss 名称/血条/当前阶段；右上分数与暂停；左下炉火 Z、绽放 E 水平同组；右下简短键盘提示。

手机：左侧摇杆，右侧炉火与绽放竖排，触屏自动射击；生命和成长位于左上，阶段/Boss 居中，暂停位于右上，战斗时收起实时分数与秒数。平板左下摇杆、右下两技能横排。

桌面主键 64×64、间隔 16；手机 56×56、竖向间隔 12；平板 72×72、横向间隔 16，单位均为 CSS 像素。采用透明深紫底、奶油白细线，炉火暖橙、绽放蓝紫。背景覆盖容器，480×270 战斗核心等比完整显示，UI 独立适配安全区域。

技能入口只有炉火与绽放。炉火库存与绽放进度各在自己的按钮内常驻显示。

## 2 灯怪击破 → 火种飞入炉火 → 次数增加

### 2.1 起点与终点

灯怪被玩家有效击破时，一枚金白色小火种从灯怪灯肚/火焰核心的位置飞出，带很短的蓝金尾迹。

**唯一终点：当前炉火按钮内的火焰图标中心。** 它与常驻的炉火库存数字构成同一资源标识区。桌面飞向左下炉火按钮，手机飞向右侧炉火按钮，平板飞向右下炉火按钮；布局交换后终点跟随实际按钮。

实现使用同一语义锚点 fireStockAnchor，从炉火图标的实际屏幕矩形取得中心。将怪物死亡点从世界坐标转换为屏幕坐标后，火种沿 UI 层弧线飞向此锚点。窗口变化或旋转后重读当前锚点，飞行连续，避免飞到旧位置。

### 2.2 时间与到账

1. 击破当步登记唯一奖励事件并预约一份库存空位。
2. 0.10 秒破灯亮焰，火种从灯肚出现。
3. 随后用 0.45 秒沿清楚的短弧线飞向炉火图标。
4. 火种抵达图标时才提交库存 +1。例如原来 1/3，飞行期间仍显示 1/3，到达时更新为 2/3。
5. 到达时图标暖橙短亮约 0.18 秒，库存数字轻跳一次，按钮附近显示“炉火 +1”约 0.6 秒，可配短促上行音。反馈范围局限于资源区。

玩家无需移动接取这枚火种。火种是奖励动效，不参与战斗碰撞；敌方火团保持橙红攻击外观，两者能通过形状、运动与归属区分。资源尾迹和到账文字保持轻量，敌弹、角色与 Boss 预警优先清晰。

### 2.3 数量与边界

炉火初始 0，上限 3。只有有效击破灯怪补充；微光推进射击成长及绽放充能，星辉用于加分。火种只补炉火次数。

已持有 + 已预约在途数量共同占用 3 格容量。同一奖励只结算一次。容量已满时按 v1.9.0 转为 100 分并提示“炉火已满 +100”，不播放一次会使人以为库存增加的入槽反馈。灯怪离场、碰撞移除或清场不发放火种。

暂停冻结火种动效和到账时间；失败清理在途奖励；进入归途或成功页前按既有规则结清有效登记奖励，避免 UI 消失后仍飞向旧按钮。

## 3 绽放累计进度：按钮内常驻进度条

### 3.1 充能来源与显示

绽放初始能量 0、上限 100。回收每颗微光 +5，充满后由玩家按 E/K 或点绽放主动开启，持续 5 秒。炉火次数与绽放能量分别计数。绽放持续中回收微光仍增加射击成长，本轮不为下一次绽放充能。

**绽放按钮内部常驻一根从左向右填充的蓝紫色水平进度条，并显示当前百分比。** 暗紫轨道始终可见，0% 时也保留空轨道。进度条与图标、名称属于同一个按钮，玩家能直接看到“已经积累多少、还差多少”。

内容层次：上部星花图标，中部“绽放”，下部百分比/状态文字及进度条；桌面 E 键帽附在按钮下缘。外圈细光仅辅助强调，累计量由内部实心进度条表达。

建议条尺寸：桌面 40×4、手机 36×4、平板 48×5 CSS 像素，均含在主按钮边界内；对比清楚的暗轨道与蓝紫填充，不依赖细光晕辨认。主键空间不足时优先保障百分比和进度条，减少星花装饰。手指松开后能看清资源变化。

数值与状态由同一份实际游戏数据驱动：充能比例 clamp(energy / 100, 0, 1)。显示百分比向下取整，低于 100 不显示就绪。回收一颗微光时可在 0.15 秒内平滑显示新增段，禁止凭表现自动补满。

### 3.2 四种状态

| 状态 | 文字 | 条与图标表现 | 操作反馈 |
| --- | --- | --- | --- |
| 累计中，0–99 | “绽放”及“35%”等真实百分比 | 空轨道常驻，蓝紫填充随能量增长；图标克制 | 尚不可开启；点按提示“收集微光，为绽放充能”，不扣资源、不排队 |
| 满槽，100 | “绽放”“就绪” | 进度条全满，星花及外圈柔和低频呼吸 | 点按或 E/K 消耗 100 能量并开启一次 |
| 开启中，5→0 秒 | “绽放”“剩余 4.2秒”等倒计时 | 同一条切换为蓝白剩余时长，从满到空；文字明确处于持续状态 | 持续期按钮不再次触发、不刷新时长；下一轮能量保持 0 |
| 结束，回到累计 | “绽放”“0%” | 持续态亮边收敛，恢复暗轨道与空充能条 | 后续回收微光重新累计 |

累计条与持续时间条共用空间，但由明确文字区分：百分比表示“充能”，剩余秒数表示“技能正在生效”。开启瞬间逻辑能量已经清零，UI 显示的是独立的 5 秒持续时间。暂停时按游戏时钟冻结进度显示与倒计时；恢复后继续。旋转、重排不清除能量，重开恢复 0。

### 3.3 视觉参考的状态含义

本目录沿用的桌面/手机 imagegen 效果图展示“炉火 2/3、绽放就绪”这一状态。它们用于确定 A 的材质与排布。累计中的进度条、火种飞行和五秒倒计时的实现以本版交互规则为准；两张静态效果图没有表现这些完整过程。

请按 A「月光悬浮」落实桌面、手机与平板 UI，并实现本版的两项必备交互：

第一，灯怪被有效击破后，火种从其灯肚飞出，0.10 秒亮焰后用 0.45 秒飞入炉火按钮内的火焰图标中心。到达时炉火次数才 +1，图标短亮、数字轻跳并出现“炉火 +1”。目标位置从实际炉火图标矩形计算，电脑、手机、平板和布局变化后均准确对齐。预约、满额溢出、暂停、失败与结算按本版及 v1.9.0 规则执行。
