# 小魔女夜巡 · 游戏源码、设计与素材

本资料包包含可直接打开的离线试玩版、可重新构建的游戏源码、完整关卡设计、精选素材，以及本地 MiniMax H3 视频生成工作流。公开整理日期：2026-10-28；补充更新：2026-10-30。

**制作过程网页：[统一入口](09-making-of/index.html) · [形象演变](09-making-of/character-evolution/小魔女形象演变.html) · [动作状态图](09-making-of/action-map/小魔女动作状态图.html) · [UI 变化路径](09-making-of/ui-evolution/小魔女UI变化路径.html) · [电脑与手机 UI 对照](09-making-of/ui-evolution/电脑与手机UI对照.html) · [音效与配乐试听](09-making-of/audio/小魔女音效与配乐.html)。**

GitHub 默认显示 HTML 源码；下载仓库后用浏览器打开即可正常阅读和试听。详细内容见 [制作过程资料说明](09-making-of/README.md)。

**完整使用说明：[使用说明.html](使用说明.html)**，包含离线试玩、源码构建、素材使用、H3 工作流与常见问题。

**离线试玩：双击根目录的 [index.html](index.html)，用桌面浏览器打开即可，无需安装依赖或启动服务。** 图片、动画、音乐和游戏逻辑均已内嵌到该文件；使用时先点击“开始夜巡”，音乐随用户交互启动。

查看资料可打开 [素材总览.html](素材总览.html)，直接看图、看动画、试听音乐。跟着视频试做，可先看 [原型策划初稿（含插图）](01-design/prototype-draft/小魔女夜巡原型策划初稿.html)；后续完整规则见 [第一关游戏策划案 v1.12.0](01-design/level-design/第一关游戏策划案.md)。

动画 PNG 是实际图集，`manifest.json` 保存帧尺寸、帧数、帧矩形和播放/锚点参数。GIF 是便于浏览的演示衍生图，不代替透明 PNG。图集已经保留完整动作，因此未重复收录大量单帧 PNG、原始抽帧和源视频。

原型策划初稿按视频口播重新整理，供首轮试做，保留了教学整理版的标注；完整策划文档保留 2026-10-24 的设计基准，素材来自整理日的工程。怪物图鉴中的数值属于更早版本，已在页面顶部标明。概念图、设计参考图和工程截图分别存放，概念图不代表实时游戏画面。此次整理未重新进行游戏验收，原验收表的状态保持不变。

本目录包含单文件离线试玩版、完整游戏源码和设计素材；构建步骤见 [DEPENDENCIES.md](DEPENDENCIES.md)，视频工作流见 [08-video-workflows/README.md](08-video-workflows/README.md)。平台专用包未重复附带。离线版本保留工程本身的功能；平台在线排行榜等联网能力不作为离线试玩保证。历史备份、补丁脚本、录屏、调试图、测试日志、助手记忆、接口配置及平台上传文件未收录。

素材来源信息见 [素材来源与使用说明](素材来源与使用说明.md)。当前没有为本包指定开源许可证；公开浏览不等于授予任意再分发或商业使用许可。第三方游戏提取素材与对标参考库未纳入本包。

`manifest.json` 是实际文件清单，记录体积、SHA-256 和图片尺寸，便于核对发布内容。
